Corbett & Co. Logo Options

Circular and oval marks abstracted from your current emblem, banner logo, and C&C stamp. Each option includes stamp positive/negative, brass & cream sticker colorways, and a mirrored file for PLA stamp molds.

Option A

Circular Seal — full name arcs + C&C center

Option B

Oval Wordmark — CORBETT & CO. + LEATHER WORKS ribbon

Option C

Circular Monogram — C & C only

Option D

Oval Monogram — outward C & C

Option E

Stitched Seal — CORBETT / & CO. stacked + stitch ring

How to use: Pick a letter (A–E). Use stamp-positive for print/laser masters; stamp-mirror when modeling a raised PLA stamp; brass/cream for sticker sheets. Prefer bold options C or D for small leather stamps; A, B, or E when you need the full name readable.
